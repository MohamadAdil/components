# UI Components Library

A collection of reusable UI components built with Bootstrap, jQuery, Font Awesome, and GSAP animations.

## Features

- Responsive design
- Clean, modern interface
- GSAP animations
- Easy to reuse components
- No server-side code required

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- jQuery
- Font Awesome
- GSAP (GreenSock Animation Platform)

## How to Use

1. Clone this repository
2. Open `index.html` in your browser
3. Browse components and click to view details
4. Copy component code for use in your projects

## Deployment

This project is ready to deploy on GitHub Pages. Just push to your repository and enable GitHub Pages in settings.
